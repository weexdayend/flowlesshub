## 4. Compose configuration and disposable runtime validation

This test uses a separate Compose project and a disposable named volume. It must not reuse a volume containing data you need.

```powershell
$compose = ".\deploy\compose\backend.compose.yaml"
$project = "flowlesshub-s02-test"

docker compose --env-file .\.env.example -p $project -f $compose config
if ($LASTEXITCODE -ne 0) { throw "Backend Compose config invalid" }

docker compose --env-file .\.env.example -p $project -f $compose up -d --build
if ($LASTEXITCODE -ne 0) { throw "Backend Compose startup failed" }

docker compose -p $project -f $compose ps -a
docker compose -p $project -f $compose logs --no-color migrate
```

Expected runtime behavior:

- `postgres` becomes healthy.
- `migrate` exits with code `0` after Goose and River migrations complete.
- `pgbouncer` becomes healthy and listens on host port `6432`.
- `api` starts only after `migrate` succeeds and PgBouncer is healthy.
- `worker` starts only after `migrate` succeeds and PostgreSQL is healthy; it connects directly to PostgreSQL for River's `LISTEN`/`NOTIFY` listener.

Verify the API probes:

```powershell
$liveness = Invoke-RestMethod http://localhost:5050/livez
$readiness = Invoke-RestMethod http://localhost:5050/readyz
$liveness.status
$readiness.status
if ($liveness.status -ne "ok") { throw "API liveness probe failed" }
if ($readiness.status -ne "ok") { throw "API readiness probe failed" }
```

Verify PgBouncer authenticates and can execute a query against PostgreSQL:

```powershell
docker compose -p $project -f $compose exec -T pgbouncer sh -lc 'PGPASSWORD="$DB_PASSWORD" psql -h 127.0.0.1 -p 5432 -U "$DB_USER" -d "$DB_NAME" -v ON_ERROR_STOP=1 -tAc "SELECT 1"'
```

Expected query result: `1`.

Check worker logs and ensure it starts without missing River table or listener errors:

```powershell
docker compose -p $project -f $compose logs --tail=100 worker
```

Re-run the one-shot migration service to prove both migration systems are idempotent:

```powershell
docker compose -p $project -f $compose up -d --force-recreate migrate
if ($LASTEXITCODE -ne 0) { throw "Migration re-run failed" }
docker compose -p $project -f $compose logs --no-color migrate
```

Stop and remove only the disposable test project and its test volume:

```powershell
docker compose -p $project -f $compose down -v
```
