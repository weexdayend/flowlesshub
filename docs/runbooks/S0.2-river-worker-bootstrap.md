## 6. Disposable Compose setup and port preflight

The previous owner test used an override because another local PostgreSQL container already owns host port `5432`. Keep that existing `postgres-db` and `adminer-web` running. This acceptance test publishes FlowlessHub PostgreSQL on `55432` and PgBouncer on `56432`; container-to-container URLs remain unchanged.

```powershell
$compose = '.\deploy\compose\backend.compose.yaml'
$envFile = '.\.env.example'
$override = Join-Path $env:TEMP 'flowlesshub-s02-ports.override.yaml'
$previousProject = 'flowlesshub-s02-acceptance-portfix'
$project = 'flowlesshub-s02-worker-acceptance'

if (-not (Test-Path $override)) {
@'
services:
  postgres:
    ports: !override
      - "55432:5432"

  pgbouncer:
    ports: !override
      - "56432:5432"
'@ | Set-Content -Path $override -Encoding utf8
}

# Remove only the previous disposable S0.2 acceptance project. Its volume was
# created by the preceding validation run, not by the existing postgres-db.
docker compose --env-file $envFile -p $previousProject -f $compose -f $override down --volumes --remove-orphans
if ($LASTEXITCODE -ne 0) { throw 'Could not clean the previous disposable acceptance project.' }

# Ensure a unique clean project/volume for this fresh runtime acceptance.
docker compose --env-file $envFile -p $project -f $compose -f $override down --volumes --remove-orphans
if ($LASTEXITCODE -ne 0) { throw 'Could not clean a prior worker-acceptance project.' }

foreach ($port in @(5050, 55432, 56432)) {
    $listener = Get-NetTCPConnection -LocalPort $port -State Listen -ErrorAction SilentlyContinue
    if ($listener) { throw "Host port $port is occupied. Stop only the conflicting test service or choose a free host port." }
}

# Existing unrelated local database containers must remain up.
$existingPostgres = docker inspect --format '{{.State.Status}}' postgres-db
if ($LASTEXITCODE -ne 0 -or $existingPostgres -ne 'running') {
    throw 'The pre-existing postgres-db container is not running; inspect it before continuing.'
}
$existingAdminer = docker inspect --format '{{.State.Status}}' adminer-web
if ($LASTEXITCODE -ne 0 -or $existingAdminer -ne 'running') {
    throw 'The pre-existing adminer-web container is not running; inspect it before continuing.'
}

docker compose --env-file $envFile -p $project -f $compose -f $override config --quiet
if ($LASTEXITCODE -ne 0) { throw 'Backend Compose configuration is invalid.' }
```

```powershell
$migrateId = docker compose -p $project -f $compose -f $override ps -aq migrate | Select-Object -First 1
```

Expected logs include successful Goose migration to version `1` and River schema current with newly applied migrations. Do not accept merely created or running API/worker containers without the migration exit code check.

## 9. Verify API, PgBouncer, and worker stability

```powershell
$liveness = Invoke-RestMethod http://localhost:5050/livez
$readiness = Invoke-RestMethod http://localhost:5050/readyz
if ($liveness.status -ne 'ok') { throw 'API liveness failed.' }
if ($readiness.status -ne 'ok') { throw 'API readiness failed.' }

$queryOutput = docker compose -p $project -f $compose -f $override exec -T pgbouncer sh -lc 'PGPASSWORD="$DB_PASSWORD" psql -h 127.0.0.1 -p 5432 -U "$DB_USER" -d "$DB_NAME" -v ON_ERROR_STOP=1 -tAc "SELECT 1"'
if ($LASTEXITCODE -ne 0 -or ($queryOutput | Out-String).Trim() -ne '1') {
    throw "PgBouncer authenticated SELECT 1 failed: $queryOutput"
}

$workerId = docker compose -p $project -f $compose -f $override ps -q worker | Select-Object -First 1
if (-not $workerId) { throw 'Worker container was not created.' }

Start-Sleep -Seconds 12
$workerState = docker inspect --format '{{.State.Status}}' $workerId
$workerRestarting = docker inspect --format '{{.State.Restarting}}' $workerId
$workerRestartCount = [int](docker inspect --format '{{.RestartCount}}' $workerId)

$workerLogs = docker compose -p $project -f $compose -f $override logs --no-color --tail=100 worker | Out-String
Write-Host $workerLogs
if ($workerState -ne 'running' -or $workerRestarting -ne 'false' -or $workerRestartCount -ne 0) {
    throw "River worker is not stable. State=$workerState Restarting=$workerRestarting RestartCount=$workerRestartCount"
}
if ($workerLogs -match 'at least one Worker must be added to the Workers bundle') {
    throw 'River still reports an empty Workers registry.'
}
if ($workerLogs -notmatch 'River worker started' -or $workerLogs -notmatch 'flowlesshub_platform_bootstrap_noop') {
    throw 'Expected structured River worker startup log and reserved bootstrap kind were not found.'
}
```

Expected worker log contains a structured `River worker started` event, includes `flowlesshub_platform_bootstrap_noop` as the reserved handler, and reports that no business handlers are registered in S0. The log must not contain `at least one Worker must be added to the Workers bundle`.

## 10. Verify migration idempotency after worker startup

```powershell
docker compose --env-file $envFile -p $project -f $compose -f $override up -d --force-recreate migrate
if ($LASTEXITCODE -ne 0) { throw 'Migration idempotency rerun failed to start.' }

$migrateId = docker compose -p $project -f $compose -f $override ps -aq migrate | Select-Object -First 1
$migrateExit = docker inspect --format '{{.State.ExitCode}}' $migrateId
docker compose -p $project -f $compose -f $override logs --no-color migrate
if ($migrateExit -ne '0') { throw "Idempotent migration rerun failed with exit code $migrateExit." }

$workerStateAfterMigration = docker inspect --format '{{.State.Status}}' $workerId
if ($workerStateAfterMigration -ne 'running') {
    throw 'River worker stopped after the migration idempotency rerun.'
}
```

Expected logs show Goose has no migrations to run and River reports `new_migrations: 0`. No duplicate-schema or migration-history errors are acceptable.
