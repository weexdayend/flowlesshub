# S0.1 CI Repair — Windows PowerShell Runbook

**Baseline:** `6930e4217ae544284763679a63d85790aa6ea7d2`

This repair fixes the failed Corepack pnpm bootstrap, makes Go module metadata a required reproducible input, corrects root Go scripts, and makes both Docker builds consume committed lock/checksum files.

Run from the repository root. Keep the working tree clean and verify the exact baseline:

## 2. Generate the dependency lock and Go checksums

Use Node.js `22.16.0`, pnpm `12.18.0`, and Go `1.27.4`. Patch and runbook files may stay untracked in the repository root; the preflight deliberately checks only tracked files and the Git index.

```powershell
node --version
$pnpmCommand = Get-Command pnpm -ErrorAction SilentlyContinue
if ($null -eq $pnpmCommand -or (pnpm --version).Trim() -ne "12.18.0") {
    npm install --global pnpm@12.18.0
    if ($LASTEXITCODE -ne 0) { throw "Installing pnpm 12.18.0 failed" }
}
pnpm --version
go version
if ((node --version).Trim() -ne "v22.16.0") { throw "Expected Node.js v22.16.0" }
if ((pnpm --version).Trim() -ne "12.18.0") { throw "Expected pnpm 12.18.0" }
if ((go version) -notmatch "go1\.27\.4") { throw "Expected Go 1.27.4" }

pnpm install --no-frozen-lockfile
if ($LASTEXITCODE -ne 0) { throw "pnpm install failed" }

pnpm api:generate
if ($LASTEXITCODE -ne 0) { throw "OpenAPI TypeScript generation failed" }

go -C .\services\api mod tidy
if ($LASTEXITCODE -ne 0) { throw "go mod tidy failed" }

go -C .\services\api mod tidy -diff
if ($LASTEXITCODE -ne 0) { throw "Go module metadata is not tidy" }

go -C .\services\api mod verify
if ($LASTEXITCODE -ne 0) { throw "Go module verification failed" }
```

Expected generated files:

```powershell
Test-Path .\pnpm-lock.yaml
Test-Path .\services\api\go.sum
Test-Path .\packages\api-client\src\generated\openapi.d.ts
```

All three must return `True`. Do not hand-write `go.sum` or generated OpenAPI types.
