```powershell

$download = Join-Path $toolDir "squawk-windows-x64.exe"
```

## 3. Positive migration lint

Squawk explicitly enables its opt-in `require-timeout-settings` rule and is told that Goose wraps each migration direction in a transaction so the existing `SET LOCAL` timeouts are evaluated in the correct execution context. PostgreSQL 17 matches the current local database image.

```powershell
& $Squawk --pg-version=17.0 --assume-in-transaction --include=require-timeout-settings "services/api/db/migrations/*.sql"
if ($LASTEXITCODE -ne 0) { throw "Squawk reported migration issues" }
```

Expected: exit code `0` and no lint findings. The timeout rule is opt-in in Squawk, so `--include=require-timeout-settings` is intentional and must not be removed. The one `ban-drop-schema` ignore is attached only to the intended `DROP SCHEMA` in the initial migration's Down section; do not replace it with a global Squawk exclusion.

## 4. Negative migration-lint probe

This temporary file deliberately omits both timeouts before a potentially locking DDL statement. It must fail lint and report both rules. The file is always removed.

```powershell
$probe = Join-Path (Resolve-Path ".\services\api\db\migrations") "99999_squawk_negative_probe.sql"
if (Test-Path $probe) { throw "Probe path already exists: $probe" }

try {
    $probeSql = @'
-- +goose Up
ALTER TABLE public.squawk_probe ADD COLUMN unsafe_text text;
'@
    $probeSql | Set-Content -Path $probe -Encoding utf8

    $probeOutput = (& $Squawk --pg-version=17.0 --assume-in-transaction --include=require-timeout-settings $probe 2>&1 | Out-String)
    $probeExit = $LASTEXITCODE
    if ($probeExit -eq 0) { throw "Squawk unexpectedly accepted the unsafe migration probe" }
    if ($probeOutput -notmatch "require-lock-timeout") { throw "Missing require-lock-timeout diagnostic`n$probeOutput" }
    if ($probeOutput -notmatch "require-statement-timeout") { throw "Missing require-statement-timeout diagnostic`n$probeOutput" }
    Write-Host "Negative Squawk probe passed: both timeout rules were enforced."
}
finally {
    if (Test-Path $probe) { Remove-Item -Force $probe }
}

& $Squawk --pg-version=17.0 --assume-in-transaction --include=require-timeout-settings "services/api/db/migrations/*.sql"
if ($LASTEXITCODE -ne 0) { throw "Committed migration lint failed after probe cleanup" }
```
