## 3. Focused hybrid handshake test

```powershell
go -C .\services\api test ./internal/platform/transportsecurity `
    -run '^TestTLS13NegotiatesX25519MLKEM768$' `
    -count=1 -v

if ($LASTEXITCODE -ne 0) {
    throw 'Focused X25519MLKEM768 TLS handshake test failed.'
```

Expected output includes:


The test configures both in-process peers for TLS 1.3 and the single `X25519MLKEM768` key-exchange group. It verifies the negotiated protocol and key-exchange group from `http.Response.TLS`.

## 4. Backend static and quality gates

```powershell
$goFiles = @(
    Get-ChildItem .\services\api\cmd, .\services\api\internal `
        -Recurse -File -Filter '*.go' |
        ForEach-Object { $_.FullName }
)

$unformatted = @(gofmt -l $goFiles)
if ($unformatted.Count -gt 0) {
    throw "Go files are not gofmt-clean: $($unformatted -join ', ')"
}

Push-Location .\services\api
try {
    go mod tidy -diff
    if ($LASTEXITCODE -ne 0) { throw 'Go module metadata is not tidy.' }

    go mod verify
    if ($LASTEXITCODE -ne 0) { throw 'Go module verification failed.' }

    go run github.com/fe3dback/go-arch-lint@v1.19.1 check --project-path .
    if ($LASTEXITCODE -ne 0) { throw 'Go module-boundary lint failed.' }

    go vet ./...
    if ($LASTEXITCODE -ne 0) { throw 'Go vet failed.' }

    go test ./... -count=1
    if ($LASTEXITCODE -ne 0) { throw 'Full Go test suite failed.' }
}
finally {
    Pop-Location
}
```
