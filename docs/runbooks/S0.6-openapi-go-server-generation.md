# FlowlessHub S0.6 — OpenAPI Go Strict Server Generation Runbook

**Patch baseline:** `c60c22a9455780f698b40d6e14fa431049bd6acf`

**Target:** Windows PowerShell 5.1+ or PowerShell 7+, Git, Go 1.27.4, Node.js >=22.13.1, pnpm 12.18.0. Backend CI uses Ubuntu and the same pinned generator version.

This runbook applies the S0.6 source/config/CI patch, generates the committed Go artifact with `oapi-codegen` v2.8.1, validates repeatability and the full repository quality gates, then stages, commits and pushes the exact scope. Do not hand-write or hand-edit the generated Go file.

## 1. Artifact relocation, baseline and clean preflight

Run from the repository root. **The patch file must be moved outside the repository before checking `git status`.** A `.patch` file downloaded into the repository root is an untracked file and will correctly make the clean-tree guard fail. The runbook handles this automatically and safely.

This block accepts the patch either in the repository root or already in `%TEMP%`. If both copies exist, it compares SHA-256 and removes the repository copy only when the two files are byte-identical. If they differ, it stops without deleting either file.

```powershell
# Resolve and enter the repository root regardless of the current directory.
$repoRoot = (git rev-parse --show-toplevel | Out-String).Trim()
if ($LASTEXITCODE -ne 0 -or [string]::IsNullOrWhiteSpace($repoRoot)) {
    throw "Unable to resolve Git repository root"
}
Set-Location $repoRoot

# Relocate the downloaded patch before clean-tree validation.
$patchName = "FLOWLESSHUB-S0.6-OPENAPI-GO-STRICT-SERVER.patch"
$patchInRepo = Join-Path $repoRoot $patchName
$patchInTemp = Join-Path $env:TEMP $patchName

$hasRepoPatch = Test-Path -LiteralPath $patchInRepo -PathType Leaf
$hasTempPatch = Test-Path -LiteralPath $patchInTemp -PathType Leaf

if ($hasRepoPatch -and $hasTempPatch) {
    $repoHash = (Get-FileHash -LiteralPath $patchInRepo -Algorithm SHA256).Hash
    $tempHash = (Get-FileHash -LiteralPath $patchInTemp -Algorithm SHA256).Hash
    if ($repoHash -ne $tempHash) {
        throw "Different patch files exist in repository root and TEMP. Neither file was changed. Inspect both copies."
    }
    Remove-Item -LiteralPath $patchInRepo -Force
}
elseif ($hasRepoPatch) {
    Move-Item -LiteralPath $patchInRepo -Destination $patchInTemp
}
elseif (-not $hasTempPatch) {
    throw "Patch not found. Place $patchName in the repository root or %TEMP%."
}

$patch = $patchInTemp
if (-not (Test-Path -LiteralPath $patch -PathType Leaf)) {
    throw "Patch relocation failed: $patch"
}
Write-Host "Patch staged outside repository: $patch" -ForegroundColor Green

# Verify exact base commit.
$expectedHead = "c60c22a9455780f698b40d6e14fa431049bd6acf"
$actualHead = (git rev-parse HEAD).Trim()
if ($LASTEXITCODE -ne 0) { throw "Unable to read Git HEAD" }
if ($actualHead -ne $expectedHead) { throw "Unexpected HEAD: $actualHead" }

# Verify exact source blobs to prevent applying against a drifted baseline.
$expectedBlobs = @{
    "Makefile" = "edd9378b38daf5dcb493a3d7b7cd21d5d56ed067"
    ".github/workflows/ci.yml" = "10b272156832bf80d8abbeab4043b309bcafee03"
    "services/api/oapi-codegen.yaml" = "735e97344793f5f5156fe7d80ed11a96e9eb9cc4"
}
foreach ($path in $expectedBlobs.Keys) {
    $actualBlob = (git rev-parse "HEAD:$path").Trim()
    if ($LASTEXITCODE -ne 0) { throw "Unable to resolve blob for $path" }
    if ($actualBlob -ne $expectedBlobs[$path]) { throw "Unexpected baseline blob for ${path}: $actualBlob" }
}

# Only now verify the clean repository state; the patch is already outside it.
$status = @(git status --short --untracked-files=all)
if ($status.Count -gt 0) {
    throw "Repository must be clean before applying patch: $($status -join ', ')"
}

git diff --quiet
if ($LASTEXITCODE -ne 0) { throw "Tracked working-tree changes detected" }
git diff --cached --quiet
if ($LASTEXITCODE -ne 0) { throw "Staged changes detected" }
```

Do not reset, clean, or delete unrelated repository files. Resolve unrelated work separately. Keep the patch in `%TEMP%` for the remainder of the runbook.

## 2. Apply the patch

Windows Git may check out Markdown/YAML/Makefile files with CRLF when `core.autocrlf=true`, so use `--ignore-space-change` for patch matching. The `$patch` variable is already set by Section 1; do not move the file back into the repository.

```powershell
git apply --ignore-space-change --check $patch
if ($LASTEXITCODE -ne 0) { throw "S0.6 patch preflight failed" }

git apply --ignore-space-change $patch
if ($LASTEXITCODE -ne 0) { throw "S0.6 patch application failed" }

git -c core.whitespace=cr-at-eol diff --check
if ($LASTEXITCODE -ne 0) { throw "Whitespace validation failed" }

git status --short
git diff --stat
```

Expected patch paths at this point:

```text
 M .github/workflows/ci.yml
 M Makefile
 M services/api/oapi-codegen.yaml
?? docs/runbooks/S0.6-openapi-go-server-generation.md
?? docs/slices/S0.6-openapi-go-server-generation.md
```

The generated Go file is not part of the patch. It is created in the next step by the pinned generator and must be committed with this slice.

## 3. Verify toolchain and generate Go server stubs

```powershell
$goText = (go version | Out-String).Trim()
if ($goText -notmatch "go1\.27\.4") { throw "Expected Go 1.27.4; found $goText" }

$nodeText = (node --version).Trim().TrimStart('v')
if ([Version]$nodeText -lt [Version]'22.13.1') { throw "Node.js >=22.13.1 required; found $nodeText" }
if ((pnpm --version).Trim() -ne "12.18.0") { throw "Expected pnpm 12.18.0" }

New-Item -ItemType Directory -Force .\services\api\internal\platform\httpapi | Out-Null
Push-Location .\services\api
try {
    go run github.com/oapi-codegen/oapi-codegen/v2/cmd/oapi-codegen@v2.8.1 --config oapi-codegen.yaml ..\..\api\openapi.yaml
    if ($LASTEXITCODE -ne 0) { throw "oapi-codegen generation failed" }
}
finally {
    Pop-Location
}

$generated = ".\services\api\internal\platform\httpapi\openapi.gen.go"
if (-not (Test-Path -LiteralPath $generated -PathType Leaf)) { throw "Generated file missing: $generated" }

$generatedText = Get-Content -LiteralPath $generated -Raw
foreach ($required in @("package platformapi", "type ServerInterface interface", "type StrictServerInterface interface", "func HandlerFromMux", "func NewStrictHandler")) {
    if ($generatedText -notmatch [regex]::Escape($required)) { throw "Generated output is missing expected declaration: $required" }
}

Write-Host "Generated OpenAPI Go server stubs successfully." -ForegroundColor Green
```

The generated file must be treated as read-only output. To change generated code, edit the OpenAPI source or generator config, then rerun the pinned command.

## 4. Prove generator determinism

```powershell
$beforeHash = (Get-FileHash -LiteralPath $generated -Algorithm SHA256).Hash
Push-Location .\services\api
try {
    go run github.com/oapi-codegen/oapi-codegen/v2/cmd/oapi-codegen@v2.8.1 --config oapi-codegen.yaml ..\..\api\openapi.yaml
    if ($LASTEXITCODE -ne 0) { throw "Second oapi-codegen generation failed" }
}
finally {
    Pop-Location
}
$afterHash = (Get-FileHash -LiteralPath $generated -Algorithm SHA256).Hash
if ($beforeHash -ne $afterHash) { throw "OpenAPI Go generation is not deterministic" }

$generatedDiff = @(git diff -- $generated)
if ($generatedDiff.Count -gt 0) { throw "Generated Go output changed on a repeat generation" }
```

The current Windows `go-arch-lint` v1.19.1 behavior has a documented seven-diagnostic false-positive set for allowed composition-root imports. Do not weaken `.go-arch-lint.yml` to silence it. Exact-HEAD Ubuntu CI must pass `Verify Go module boundaries`; this runbook does not record the Windows diagnostic as a local pass.

Optional race detector (requires a working C compiler on Windows):


## 11. Mandatory patch-artifact handling for future Windows bakes

Every subsequent FlowlessHub PowerShell runbook must follow the same order used above:

1. Resolve the Git root.
2. Move a downloaded `.patch` from the repository root to `%TEMP%` before running any clean-tree check.
3. If both copies exist, compare SHA-256; remove the repository copy only if identical, otherwise stop.
4. Verify exact HEAD and baseline blob SHAs.
5. Require a clean tracked/index/untracked state.
6. Run `git apply --ignore-space-change --check`, then apply.
7. Run `git -c core.whitespace=cr-at-eol diff --check`.

Never ask the owner to put the patch in the repository root and then run `git status` first. Keep the patch in `%TEMP%` through validation and commit. This is the standard for all future FlowlessHub patch deliveries, not a one-off S0.6 workaround.
