**Purpose:** Prove that local `main` and live `origin/main` are exactly the audited patch base.


## 2. Verify patch identity and test apply compatibility

Save the patch outside the repository, preferably in `$HOME\Downloads`. Copy the expected SHA-256 from the delivered `FLOWLESSHUB-S0.11-SHA256SUMS.txt` manifest. Do not edit or re-save the patch file.

**[WINDOWS — POWERSHELL]**
**Directory:** `C:\Projects\saas\flowlesshub`
**Mode:** Read-only
**Purpose:** Verify the exact patch bytes and run Git's strict whitespace preflight.
**Preconditions / stop:** Expected hash must be copied from the handoff manifest. Stop on any mismatch or non-zero exit.

```powershell
$PatchPath = Join-Path $HOME 'Downloads\FLOWLESSHUB-S0.11-BACKUP-OPS-AND-CONTINUITY.patch'
$ExpectedPatchSha256 = 'REPLACE_WITH_PATCH_SHA256_FROM_HANDOFF_MANIFEST'
if (-not (Test-Path -LiteralPath $PatchPath -PathType Leaf)) { throw "Patch not found: $PatchPath" }

$ActualPatchSha256 = (Get-FileHash -LiteralPath $PatchPath -Algorithm SHA256).Hash.ToLowerInvariant()
if ($ActualPatchSha256 -ne $ExpectedPatchSha256.ToLowerInvariant()) {
    throw "Patch SHA-256 mismatch. Expected=$ExpectedPatchSha256 Actual=$ActualPatchSha256"
}

git apply --check --whitespace=error-all $PatchPath
if ($LASTEXITCODE -ne 0) { throw 'git apply --check failed; do not force the patch.' }
Write-Host "Patch SHA-256 verified: $ActualPatchSha256" -ForegroundColor Green
```

## 8. VPS boundary after CI

Patch application and source/configuration CI do not require VPS access. Do not install the systemd service/timer, run Restic, provision cloud credentials, initialize a repository, upload backups, or delete local artifacts as part of the Windows apply steps.

Only after the exact pushed SHA passes CI should the separate [S0.11 Scheduled Backup Operations Runbook](S0.11-scheduled-backup-operations.md) be used for read-only VPS inspection. The timer is not to be enabled while policy decisions remain open.
