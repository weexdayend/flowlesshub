## Changes

- First-install deployment is resumable after partial FlowlessHub-only startup. It preserves the FlowlessHub PostgreSQL volume and refuses to overwrite an unexpected runtime Caddy configuration.
- VPS preflight verifies Docker/Compose, Nginx, disk/RAM, loopback port ownership, runtime `.env` mode `0600`, Git ignore coverage, and deployment lock support. It does not mutate Nginx or Petshop resources.
- Release and rollback environment updates are written to mode-`0600` temporary files, Compose-validated, and atomically installed while holding the FlowlessHub deployment lock. Protected backups are retained.
- Blue/green switching serializes deployment operations, keeps the previous Caddy config until the switch is committed, and attempts automatic restoration/reload after a failed switch. An unconfirmed restoration retains a manual recovery copy.
- Worker update checks that exactly one worker container is running and that River startup was observed. Worker business handlers remain unregistered in this slice.
- GitHub CI validates Bash syntax, ShellCheck warnings, Docker Compose configuration interpolation, both Caddyfiles, and the additive Nginx site configuration. These run on the GitHub-hosted runner; local Docker runtime is not a required gate.
- GHCR publication is gated on the release commit being reachable from `main` and a successful `push` CI run for that exact commit SHA.
- The VPS deployment runbook now defines laptop/GitHub/VPS responsibilities and keeps actual runtime acceptance on the VPS.

## Acceptance boundary

GitHub CI success establishes source/configuration gates only. It does not establish that Docker containers start on the target VPS, that GHCR pulls work with its registry permissions, that available RAM permits blue/green overlap, or that public DNS/TLS/Nginx routing works. Those claims remain pending until observed and recorded on the actual host.

No command in this slice stops or recreates Petshop containers, changes Petshop networks/volumes, performs a global Docker prune, or replaces existing Frictiona/Petshop Nginx virtual hosts.
